# SmartCart Clustering System

## Project Overview

SmartCart Clustering System is an **unsupervised machine learning project** designed to analyse and segment e-commerce customers based on their demographic information, purchasing behaviour, website activity, and campaign responses.

The project uses customer transaction and behavioural data to discover hidden patterns and group customers with similar characteristics.

## Objective

The main objective of this project is to create meaningful customer segments that can help businesses:

-  Understand different customer behaviour patterns
-  Develop personalised marketing strategies
-  Identify high-value customers
-  Improve customer engagement and loyalty
-  Identify potential churn-prone customers
-  Support data-driven business decisions

## Dataset

The dataset contains **2,240 customer records** with **22 attributes** covering areas such as:

- Customer demographics
- Purchase behaviour
- Product spending
- Website activity
- Campaign responses
- Customer engagement and loyalty indicators

## Machine Learning Approach

Since there are no predefined customer segments, **unsupervised learning** techniques are used to discover natural groupings within the data.

The project involves:

1. Data preprocessing and cleaning
2. Exploratory Data Analysis (EDA)
3. Feature engineering
4. Feature scaling
5. Dimensionality reduction
6. Customer clustering
7. Cluster evaluation
8. Customer segment interpretation

## Clustering Techniques

The project explores clustering algorithms such as:

- **K-Means Clustering**
- **Hierarchical Clustering**
- **DBSCAN**

The resulting clusters are analysed to understand the characteristics and behaviour of each customer segment.

## Business Impact

The identified customer segments can help SmartCart move from a **generic marketing strategy** to a more targeted approach.

For example, different strategies can be developed for:

- High-value and loyal customers
- Frequent purchasers
- Low-engagement customers
- Potential churn-prone customers
- New or less-engaged customers

This enables more effective marketing campaigns, better customer retention, and improved resource allocation.
